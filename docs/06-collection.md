# 06. 도감 구현 지침

**도감**은 지금까지 낚은 물고기 종류를 모아 보는 화면입니다. 20종을 모두 모으는 것이 이 게임의 최종 목표입니다.

---

## 1. 도감 기록 구조

`state.collection`은 **물고기 id를 열쇠로 하는 객체**다. 한 번도 낚지 않은 물고기는 열쇠가 없다.

```js
state.collection = {
  crucian: {
    count: 12,                              // 낚은 총 마리 수 (판매해도 줄지 않음)
    maxSize: 28.7,                          // 지금까지 가장 큰 크기 (cm)
    firstCaughtAt: '2026-11-23T07:12:00.000Z'
  },
  // ...
};
```

---

## 2. 기록 갱신 규칙 (낚시 성공할 때마다)

함수 `recordCatch(fishId, size)` (js/collection.js 또는 state.js)가 아래를 처리하고 결과를 돌려준다.

| 상황 | 처리 | 결과 모달 표시 |
|---|---|---|
| 처음 낚은 종류 | 기록 새로 만들기 (`count: 1`, `maxSize: size`, `firstCaughtAt: 지금`) | `NEW!` 배지 |
| 이미 있는 종류, 크기가 기존 최대보다 큼 | `count` +1, `maxSize` 갱신 | `최대 기록!` 배지 |
| 이미 있는 종류, 크기가 같거나 작음 | `count` +1 | 배지 없음 |

- 처음 낚은 경우에는 `NEW!`만 표시하고 `최대 기록!`은 표시하지 않는다.
- 돌려주는 값: `{ isNew: boolean, isRecord: boolean }`

---

## 3. 지역 도감 완성 보상

- 어떤 지역의 물고기 5종을 **모두** 도감에 등록하면, 그 지역의 `completeReward`(docs/04 3장) 골드를 **한 번만** 준다.
- 받은 지역 id는 `state.claimedRegionRewards` 배열에 넣어, 다시 받지 못하게 한다.
- 지급 시점: 결과 모달이 **닫힌 직후** 토스트 `🎉 잔잔한 호수 도감 완성! 보상 300G를 받았어요`.
- 보상 금액은 `stats.totalEarned`에도 더한다.

---

## 4. 전체 완성

- 20종을 모두 등록하면, 결과 모달이 닫힌 뒤 축하 모달을 한 번 띄운다.
  - 내용: `👑` (72px) / `낚시왕 달성!` / `20종의 물고기를 모두 모았어요.` / [확인]
- 이후 상단바 골드 옆에 `👑 낚시왕` 배지를 항상 표시한다(docs/02).
- 축하 모달을 이미 봤는지 `state.kingAchieved`(true/false)로 기록한다.
- 같은 결과 모달 뒤에 지역 보상과 전체 완성이 함께 생기면 **지역 보상 토스트 → 축하 모달** 순서.

---

## 5. 도감 화면

### 5-1. 맨 위 요약
- `도감 달성률 {등록 수}/20 ({백분율}%)` — 백분율은 정수로 반올림.
- 아래에 진행 막대.

### 5-2. 지역별 묶음
- 순서: 잔잔한 호수 → 맑은 강 → 푸른 바다 → 심해 협곡 (해금 여부와 관계없이 4개 모두 표시).
- 묶음 제목: `잔잔한 호수  3/5`, 보상을 받았으면 `✅ 보상 받음`, 아직이면 `완성 보상 300G`.
- 아직 해금하지 않은 지역 묶음은 제목 옆에 `🔒`를 붙인다(카드는 똑같이 ??? 로 보임).
- 묶음 안 카드 순서는 docs/04 표의 순서.

### 5-3. 카드
| 상태 | 표시 |
|---|---|
| 발견 | 이모지(36px), 이름, 등급 배지 |
| 미발견 | `❔`, `???`, 회색 배경. 등급 배지는 표시하지 않음 |

### 5-4. 상세 모달 (발견한 카드를 눌렀을 때)
```
        🐠
      황금 잉어
     [ 전설 ]
  보면 행운이 온다는 전설의 잉어
  ───────────────
  사는 곳     잔잔한 호수
  낚은 수     3마리
  최대 크기   94.1cm
  크기 범위   50 ~ 100cm
  처음 낚은 날 2026.11.23
       [닫기]
```
- 날짜 형식: `YYYY.MM.DD` (사용자 기기 시간대 기준).

---

## 6. 완료 기준·검증 기준

- [ ] 처음 낚은 물고기는 결과 모달에 `NEW!`가 뜨고, 도감에서 `???`가 실제 카드로 바뀐다.
- [ ] 같은 물고기를 더 크게 낚으면 `최대 기록!`이 뜨고 상세 모달의 최대 크기가 바뀐다.
- [ ] 물고기를 팔아도 도감의 낚은 수가 줄지 않는다.
- [ ] 호수 5종을 모두 모으면 300G 보상 토스트가 뜨고 골드가 300 늘어난다. 이후 다시 주지 않는다.
- [ ] 새로고침해도 도감 기록과 보상 받음 표시가 유지된다.
- [ ] 20종을 모두 모으면 축하 모달이 한 번 뜨고, 상단바에 `👑 낚시왕`이 계속 보인다.
