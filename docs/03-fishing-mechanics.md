# 03. 낚시 기능 구현 지침

낚시 한 번의 흐름(상태)과 릴 감기 미니게임의 **모든 동작 수치**를 정합니다.
여기 나온 수치는 `js/data.js`의 `FISHING_CONFIG` 객체에 넣고, 코드에서는 그 상수를 참조합니다.

---

## 1. 낚시 상태 (상태 기계)

낚시는 항상 아래 7개 상태 중 **하나**에만 있습니다. `js/fishing.js`에서 `currentState` 변수로 관리합니다(저장하지 않음).

```
IDLE ──던지기──▶ CHARGING ──멈춤──▶ WAITING ──시간 지남──▶ BITE ──챔질 성공──▶ REELING
 ▲                                   │                     │                    │
 │                              너무 일찍 누름          시간 초과            성공/실패/시간초과
 │                                   ▼                     ▼                    ▼
 └──────────────────────────────── IDLE ◀────────────── IDLE            RESULT ──확인──▶ IDLE
```

| 상태 | 뜻 | 상태 문구 | 메인 버튼 글자 | 탭 이동 |
|---|---|---|---|---|
| IDLE | 대기 | `낚싯대를 던져보세요` | `낚싯대 던지기 (Space)` | 가능 |
| CHARGING | 힘 조절 중 | `좋은 타이밍에 멈추세요!` | `던지기! (Space)` | 불가 |
| WAITING | 입질 기다리는 중 | `물고기를 기다리는 중…` | `기다리는 중…` | 불가 |
| BITE | 입질! | `지금이에요! 당기세요!` | `챔질! (Space)` | 불가 |
| REELING | 릴 감기 | `물고기를 잡기 영역 안에 두세요` | `꾹 눌러서 감기 (Space)` | 불가 |
| RESULT | 결과 모달 표시 | (이전 문구 유지) | (모달 버튼 사용) | 불가 |

- 상태가 바뀔 때마다 상태 문구, 메인 버튼 글자, 탭 활성 여부, 미끼 선택 활성 여부를 **한 함수(`setState(next)`)에서** 함께 갱신한다.
- 미끼 선택 `<select>`는 IDLE에서만 바꿀 수 있다.

## 2. 상태별 상세 규칙

### 2-1. IDLE → CHARGING (던지기 버튼)
메인 버튼을 누르면 순서대로 검사한다.
1. 가방이 가득 찼으면(`bag.length >= bagCapacity`) → 오류 E01 토스트, **IDLE 유지**.
2. 선택한 미끼가 특수 미끼인데 보유 개수가 0이면 → 기본 미끼로 바꾸고 E03 토스트, 그다음 계속 진행.
3. CHARGING으로 바꾸고 힘 게이지를 움직이기 시작한다.

### 2-2. CHARGING (힘 조절)
- 힘 값 `power`는 0에서 100까지 올라갔다가 다시 0으로 내려오기를 반복한다.
- 한 번 왕복(0→100→0)에 **1.6초**(올라가기 0.8초, 내려오기 0.8초). 일정한 속도.
- 메인 버튼을 누르면 그 순간의 `power`(정수로 반올림)를 기록한다.
- **이때 미끼를 소모한다**: 특수 미끼면 보유 개수 −1. 기본 미끼는 소모하지 않는다.
- `stats.totalCasts` +1 하고 저장한다.
- 힘에 따라 기다리는 시간을 정하고 WAITING으로 간다.

| 힘(power) | 판정 | 기다리는 시간 | 토스트 |
|---|---|---|---|
| 0 ~ 39 | 약함 | 4.0 ~ 8.0초 사이 랜덤 | 없음 |
| 40 ~ 89 | 보통 | 3.0 ~ 6.0초 사이 랜덤 | 없음 |
| 90 ~ 100 | 퍼펙트 | 1.5 ~ 3.0초 사이 랜덤 | `✨ 퍼펙트 캐스팅!` |

### 2-3. WAITING (기다리기)
- 정해진 시간이 지나면 BITE로 간다.
- 기다리는 중에 메인 버튼을 누르면 → 오류 E05 토스트, **IDLE로**. (미끼는 이미 소모됨)

### 2-4. BITE (입질)
- BITE가 되는 순간 **어떤 물고기인지 결정**한다(3장).
- 화면에 `❗`를 띄우고 **1.0초** 안에 메인 버튼을 눌러야 한다.
  - 1.0초 안에 누름 → REELING.
  - 1.0초가 지남 → 오류 E06 토스트, **IDLE로**.

### 2-5. REELING (릴 감기 미니게임)
4장의 규칙을 따른다. 끝나면 RESULT로 간다.

### 2-6. RESULT (결과)
- **성공**: 결과 모달을 띄운다. 모달을 띄우기 **전에** 아래를 처리하고 저장한다.
  1. 크기와 판매가 계산(3장)
  2. 가방에 추가
  3. 도감 기록 갱신(docs/06) → NEW!, 최대 기록! 여부 결정
  4. `stats.totalCaught` +1
  5. 지역 도감 완성 보상 확인(docs/06)
- **실패**: 실패 모달(💨 + 실패 메시지)을 띄운다. 가방·도감 변화 없음.
- 모달의 `확인`(또는 Space, Esc)을 누르면 IDLE로.

## 3. 물고기 결정 규칙

### 3-1. 등급 뽑기
1. 사용한 미끼의 등급 확률표(docs/04 4장)를 가져온다.
2. `weightedPick({ common, rare, epic, legendary })`로 등급 하나를 뽑는다.
3. 디버그 모드의 "다음 물고기 전설 확정"이 켜져 있으면 등급을 `legendary`로 정하고 그 옵션을 끈다(docs/09).

### 3-2. 물고기 뽑기
- 현재 지역의 물고기 중 뽑힌 등급인 물고기들 가운데 **같은 확률로** 하나를 고른다.
- (모든 지역에 4개 등급이 다 있으므로 비는 경우는 없다.)

### 3-3. 크기
- `size = randomRange(minSize, maxSize)`를 **소수점 첫째 자리로 반올림**(cm).

### 3-4. 판매가
```
ratio = (size - minSize) / (maxSize - minSize)      // 0 ~ 1
price = Math.round(basePrice × (0.8 + 0.4 × ratio))  // 기본가의 80% ~ 120%
```
- 예: 붕어(기본가 20G, 10~30cm), 크기 20cm → ratio 0.5 → 20 × 1.0 = **20G**

## 4. 릴 감기 미니게임

### 4-1. 좌표
- 세로 게이지는 **0(바닥) ~ 100(꼭대기)** 단위로 계산한다. 화면 픽셀로 바꾸는 것은 그리기 단계에서만 한다.
- 물고기 위치 `fishY`, 잡기 영역 아래쪽 끝 `zoneY`, 잡기 영역 높이 `zoneH`.

### 4-2. 시작 값
| 값 | 시작 |
|---|---|
| `fishY` | 50 |
| `zoneH` | `ZONE_BASE_HEIGHT`(25) + 장착 낚싯대의 `zoneBonus` (docs/04) |
| `zoneY` | `50 − zoneH / 2` |
| 잡기 영역 속도 `zoneVel` | 0 |
| 진행도 `progress` | 30 (%) |
| 제한 시간 | 25초 |

### 4-3. 잡기 영역 움직임 (매 프레임, dt초마다)
```
누르고 있으면: zoneVel += ZONE_UP_ACCEL × dt        // 200 /초²
떼고 있으면:   zoneVel -= ZONE_GRAVITY × dt         // 160 /초²
zoneVel = clamp(zoneVel, -ZONE_MAX_SPEED, ZONE_MAX_SPEED)  // ±90 /초
zoneY  += zoneVel × dt
zoneY가 0보다 작으면: zoneY = 0, zoneVel = 0
zoneY가 (100 − zoneH)보다 크면: zoneY = 100 − zoneH, zoneVel = 0
```
- "누르고 있음"은 메인 버튼 누르는 중(마우스·터치) 또는 **Space 키를 누르고 있는 중**.
- 미니게임 패널(세로 게이지 포함)을 누르고 있어도 같은 것으로 본다.

### 4-4. 물고기 움직임
- 물고기는 목표 위치 `targetY`를 향해 일정한 속도로 움직인다.
- 일정 간격마다 `targetY = randomRange(0, 100)`로 새 목표를 정한다(시작할 때도 한 번).
- 목표에 도착하면 다음 목표 시간이 될 때까지 멈춰 있는다.
- 간격과 속도는 물고기의 **난이도**(docs/04)에 따른다.

| 난이도 | 목표 바꾸는 간격 | 물고기 속도 | 진행도 감소 |
|---|---|---|---|
| 1 | 1.6초 | 25 /초 | 12 %/초 |
| 2 | 1.3초 | 35 /초 | 14 %/초 |
| 3 | 1.0초 | 45 /초 | 16 %/초 |
| 4 | 0.8초 | 60 /초 | 18 %/초 |
| 5 | 0.6초 | 75 /초 | 20 %/초 |

### 4-5. 진행도
```
물고기가 잡기 영역 안 (zoneY ≤ fishY ≤ zoneY + zoneH):
    progress += PROGRESS_GAIN × 낚싯대 reelMultiplier × dt   // 22 %/초 × 배수
밖:
    progress -= 난이도별 진행도 감소 × dt
progress = clamp(progress, 0, 100)
```

### 4-6. 끝나는 조건 (먼저 일어난 것 하나)
| 조건 | 결과 | 메시지 |
|---|---|---|
| `progress`가 100 도달 | **성공** | 결과 모달 |
| `progress`가 0 도달 | 실패 | E07 |
| 25초 지남 | 실패 | E08 |

### 4-7. 기타
- `dt`가 0.1초보다 크면(탭 전환 등으로 멈췄다 돌아온 경우) 0.1초로 자른다.
- 브라우저 탭이 숨겨지면(`document.hidden`) 미니게임과 대기 시간을 **일시정지**하고, 다시 보이면 이어서 진행한다.

## 5. 키보드·터치 입력

| 입력 | 동작 |
|---|---|
| Space 누름 | 메인 버튼을 누른 것과 같음 (keydown, 누르고 있으면 반복 실행 금지: `event.repeat`이면 무시) |
| Space 누르고 있기 | REELING에서 "누르고 있음" |
| Space 뗌 | REELING에서 "뗌" |
| 메인 버튼 pointerdown / pointerup / pointerleave / pointercancel | 누름 / 뗌 / 뗌 / 뗌 |

- Space를 눌렀을 때 페이지가 스크롤되지 않게 `preventDefault()`.
- 모달이 열려 있으면 Space는 모달의 기본 버튼(확인)으로 동작한다.
- 입력 필드(`<select>`)에 포커스가 있을 때는 Space를 게임 입력으로 쓰지 않는다.

## 7. 완료 기준·검증 기준

- [ ] 던지기 → 힘 조절 → 기다리기 → 입질 → 챔질 → 릴 감기 → 결과까지 끊김 없이 진행된다.
- [ ] 힘 90 이상에서 멈추면 `✨ 퍼펙트 캐스팅!`이 뜨고 3초 안에 입질이 온다.
- [ ] 기다리는 중에 누르면 E05가 뜨고 IDLE로 돌아간다.
- [ ] 입질 후 1초 동안 안 누르면 E06이 뜨고 IDLE로 돌아간다.
- [ ] 미니게임에서 아무것도 안 누르면 잡기 영역이 바닥으로 떨어지고, 결국 E07 또는 E08로 실패한다.
- [ ] 미니게임에서 Space를 누르고 있으면 잡기 영역이 올라간다.
- [ ] 판매가가 3-4 공식과 일치한다(결과 모달의 크기로 직접 계산해 1G 차이도 없어야 함).
- [ ] 낚시 중에는 다른 탭과 미끼 선택이 눌리지 않는다.
- [ ] 미니게임 중 다른 브라우저 탭으로 갔다 오면 시간이 흐르지 않았다.
