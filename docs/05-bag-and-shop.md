# 05. 가방·상점 구현 지침

낚은 물고기를 **보관하고 파는 가방**, 골드로 **장비를 사는 상점** 규칙입니다.
가격과 효과 숫자는 `docs/04-game-data.md`를 따릅니다.

---

## 1. 가방

### 1-1. 가방에 들어가는 정보
낚시에 성공하면 아래 객체를 `state.bag` 배열 **맨 앞**에 넣는다(최신이 위).

```js
{
  uid: 'f_1732345678901_3821',  // 'f_' + Date.now() + '_' + 0~9999 랜덤 정수
  fishId: 'crucian',
  size: 23.4,                   // cm, 소수 첫째 자리
  price: 21,                    // 낚은 순간 계산해서 고정 (docs/03 3-4)
  caughtAt: '2026-11-23T07:12:00.000Z'  // new Date().toISOString()
}
```

### 1-2. 용량
- `state.bag.length`가 `state.bagCapacity` 이상이면 낚싯대를 던질 수 없다 → E01 (docs/03 2-1).
- 상단바 `🎒 7/20`은 가방이 바뀔 때마다 즉시 갱신한다.

### 1-3. 팔기
| 동작 | 규칙 |
|---|---|
| 한 마리 팔기 | 그 물고기의 `price`만큼 골드 +, 가방에서 제거, 토스트 `🪙 붕어를 21G에 팔았어요` |
| 모두 팔기 | 확인 모달 `물고기 7마리를 모두 1,230G에 팔까요?` [취소] [팔기] → 전부 판매, 토스트 `🪙 7마리를 1,230G에 팔았어요` |
| 가방이 비었을 때 | `모두 팔기` 버튼 비활성 |

- 판매하면 `stats.totalEarned`에 판매 금액을 더한다.
- 판매해도 **도감 기록은 줄어들지 않는다.**
- 판매 후 저장한다.

---

## 2. 상점

상점은 세 칸(탭)으로 나뉜다: **낚싯대 / 미끼 / 가방**. 상점을 열 때는 항상 `낚싯대` 탭이 먼저 보인다.

### 2-1. 공통 구매 규칙
1. 골드가 가격보다 적으면 → E02 토스트, 아무것도 바뀌지 않음.
2. 골드가 충분하면 → 골드 차감, 아이템 지급, 토스트 `✅ {이름} 구매 완료!`, 저장, 화면 다시 그리기.
3. 구매에는 **확인 모달을 띄우지 않는다**(바로 구매). 단, 가격이 **1,000G 이상**이면 확인 모달 `{이름}을(를) {가격}G에 살까요?`를 띄운다.

### 2-2. 낚싯대 탭
- `ROD_ORDER` 순서대로 4개를 모두 보여준다.
- 카드: `이모지 | 이름 / 설명 / "잡기 영역 +5 · 감기 속도 ×1.10" | 버튼`
- 버튼 상태:
  | 상태 | 버튼 |
  |---|---|
  | 미보유 | `구매 {가격}G` |
  | 보유, 장착 안 함 | `장착` |
  | 장착 중 | `장착 중` (비활성) |
- **구매하면 바로 장착**한다. 토스트 `✅ 카본 낚싯대 구매 완료! 바로 장착했어요.`
- `장착`을 누르면 장착만 바꾼다. 토스트 `🎣 프로 낚싯대를 장착했어요.`
- 낚시 화면의 낚싯대 표시도 바로 바뀐다.

### 2-3. 미끼 탭
- `worm`, `shiny`, `golden` 3종만 판다(기본 미끼는 팔지 않음).
- 카드: `이모지 | 이름 / 설명 / "보유 12개" | [1개 {가격}G] [10개 {가격×10}G]`
- 산 미끼는 `state.baits[id]`에 더한다. 최대 999개(docs/04 4장).
- 미끼를 처음 샀을 때 낚시 화면의 미끼 선택 목록에 나타난다. **산 미끼를 자동으로 선택하지는 않는다.**

### 2-4. 가방 탭
- 카드 하나: `🎒 | 가방 확장 / "현재 20마리 → 30마리" | 구매 400G`
- 최대(50)면 설명 `가방이 최대 크기예요 (50마리)`, 버튼 `최대 용량이에요` 비활성.
- 구매하면 `state.bagCapacity`를 다음 단계로, 토스트 `✅ 가방이 30마리로 커졌어요!`

## 3. 상태 변경 함수 (js/state.js에서 export)

| 함수 | 하는 일 | 돌려주는 값 |
|---|---|---|
| `addFishToBag(item)` | 가방 맨 앞에 추가 | 없음 |
| `sellFish(uid)` | 한 마리 판매 | 판매 금액 |
| `sellAllFish()` | 전부 판매 | `{ count, total }` |
| `spendGold(amount)` | 골드가 충분하면 차감 | 성공 `true` / 부족 `false` |
| `addGold(amount)` | 골드 추가 | 없음 |
| `buyRod(rodId)` | 구매 + 장착 | `{ ok, error }` |
| `equipRod(rodId)` | 장착 | 없음 |
| `buyBait(baitId, qty)` | 미끼 구매 | `{ ok, error }` |
| `buyBagUpgrade()` | 다음 단계 가방 확장 | `{ ok, error }` |

- `error`는 docs/08의 오류 코드 문자열(예: `'E02'`)이다.
- 모든 함수는 마지막에 `saveGame()`을 호출하고, 상단바를 갱신하도록 `ui.js`의 `refreshTopbar()`를 부른다.

## 4. 완료 기준·검증 기준

- [ ] 붕어 한 마리를 팔면 골드가 그 물고기의 가격만큼 정확히 늘어난다.
- [ ] 모두 팔기 확인 모달의 합계와 실제로 늘어난 골드가 같다.
- [ ] 가방이 가득 찬 상태에서 던지기를 누르면 E01이 뜬다. 한 마리 팔면 다시 던질 수 있다.
- [ ] 골드 100G로 카본 낚싯대(300G)를 누르면 E02가 뜨고 골드가 그대로다.
- [ ] 카본 낚싯대를 사면 바로 장착되고, 미니게임 잡기 영역이 눈에 띄게 커진다(25 → 30).
- [ ] 대나무 낚싯대로 다시 `장착`할 수 있다.
- [ ] 미끼 10개를 사면 보유 개수가 10 늘고, 던질 때마다 1씩 준다. 0이 되면 기본 미끼로 바뀌며 E03이 뜬다.
- [ ] 가방 확장을 3번 사면 50이 되고 더 이상 살 수 없다.
- [ ] 1,000G 이상 상품은 확인 모달이 뜨고, 취소하면 아무것도 바뀌지 않는다.
