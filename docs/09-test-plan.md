## 디버그 모드 (3단계에 만들고 5단계에 기능 추가)

- 주소 끝이 `#debug`일 때만 화면 오른쪽 아래에 작은 패널(접기 가능)을 띄운다.
- 디버그 모드에서 바꾼 값도 일반 상태 변경 함수를 거쳐 저장된다(골드 등).

| 버튼 | 동작 | 만드는 단계 |
|---|---|---|
| `+1,000G` | 골드 1,000 추가 (`stats.totalEarned`에는 더하지 않음) | 3 |
| `다음 물고기 전설 확정` | 켜면 다음 입질 한 번의 등급을 legendary로 고정 후 자동으로 꺼짐 | 3 |
| `입질 바로 오기` | 켜 두면 기다리는 시간이 0.5초로 고정 (끌 때까지 유지) | 3 |
| `등급 통계` | 현재 선택한 미끼로 등급 뽑기를 1,000번 해서 결과 비율을 패널에 표시 (게임 상태는 바꾸지 않음) | 5 |

## 전체 시나리오 테스트 (8단계)

데이터 초기화 후, 디버그 모드에서 처음부터 끝까지 진행한다.

1. 시작 화면: 100G, 호수, 대나무 낚싯대, 가방 0/20.
2. 호수에서 물고기 3마리 낚기 → 가방 3/20, 도감 등록 확인.
3. 2마리 한 마리씩 팔기, 1마리 모두 팔기 → 골드 증가가 판매가 합과 같은지.
4. `+1,000G` 1번 → 카본 낚싯대 구매 → 자동 장착 확인 → 미니게임 잡기 영역 커짐 확인.
5. 지렁이 미끼 10개 구매 → 선택 → 던질 때마다 1씩 감소 확인.
6. 강 해금(500G) → 이동 → 배경·물고기 변경 확인.
7. `다음 물고기 전설 확정`으로 철갑상어 낚기 → 결과 모달 전설 효과 확인.
8. 새로고침 → 2~7의 결과가 모두 유지되는지.
9. `+1,000G`를 여러 번 눌러 바다·심해까지 해금하고, 도감 20종을 모두 채우기 → 지역 보상 토스트 4번, 낚시왕 모달 1번.
10. 데이터 초기화 → 1번 상태로 돌아오는지.
